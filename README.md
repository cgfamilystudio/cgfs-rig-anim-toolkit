# cgfs-rig-anim-toolkit
CGFS RIG-ANIM TOOLKIT 
Professional Animation & Rigging Toolkit for Maya 2024 and later
CGFamilyStudio  |  https://youtube.com/@CGFamilyStudio

----------------------------------------------
INSTALL
----------------------------------------------
1. Unzip this folder anywhere (keep all the files together).
2. Open Maya (2024 and later).
3. Drag the file  installer.mel  into the Maya viewport.
4. A "CGFS" shelf button appears - click it to open the toolkit.

If dragging installer.mel does not create a shelf button, drag installer.py
into the Maya viewport instead.

----------------------------------------------
LAUNCH MANUALLY (optional)
----------------------------------------------
Script Editor (Python):
    import cgfs_anim_tools.ui.main_window as mw; mw.show_window()
